# Roselyne & Fred Wedding Website

This is a mobile-friendly first design draft for the wedding website.

## Preview
Open `index.html` in a browser.

## Included
- Main invitation page using the two supplied photographs (unaltered)
- Countdown to 12 December 2026, 10:00 AM East Africa Time
- Ceremony and reception details
- Google Maps search links
- Calendar invitation file
- Planned sections for RSVP, guestbook and guest photo/video wall

## Important before sharing with guests
The RSVP, guestbook and media-upload areas are currently marked as setup pending. They are visual placeholders, not live forms. They need a secure backend and storage service before publication. In particular, guest uploads should have file-size/type limits and moderation, and RSVP should validate one response per invitation/guest.

## Publish
A developer or a guided deployment to a hosting service such as Vercel can publish this folder. Do not share the site as a live RSVP invitation until the backend integrations are connected and tested.
